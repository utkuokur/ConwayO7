2.4 The automorphism group

Definition 17 Forgetting an automorphism to a permutation
✓
#

Lean declarations

  • ConwayO7.autToPerm

For a graph \(G\) on a vertex set \(V\), the map sending an automorphism \(\sigma \in \operatorname {Aut}G = (G \simeq _g G)\) to its underlying vertex bijection is a monoid homomorphism \(\operatorname {Aut}G \to \operatorname {Sym}(V)\).

  • ConwayO7.exists_aut_orderOf_eq_seven
  • exists_prime_orderOf_dvd_card

If \(7 \mid |\operatorname {Aut}G|\) for a graph \(G\) on a finite vertex set, then \(\operatorname {Aut}G\) contains an element of order \(7\).

Proof ▶

Cauchy’s theorem for the finite group \(\operatorname {Aut}G\) (mathlib’s exists_prime_orderOf_dvd_card) with the prime \(7\).

Lean declarations

  • ConwayO7.cycleType_autToPerm

Let \(\Gamma \) be an \(\mathrm{srg}(99,14,1,2)\) and \(\sigma \in \operatorname {Aut}\Gamma \) with \(\operatorname {ord}\sigma = 7\). Then the underlying vertex permutation of \(\sigma \) has cycle type \([7^{14}]\).

Proof ▶

An injective homomorphism preserves orders, so the underlying permutation also has order \(7\) and preserves adjacency; apply Theorem 16.
