4.2 The block-relabelling subgroup

Definition 67 Relabelling generators
✓
#

Uses

  • Lemma 33

Lean declarations

  • ConwayO7.Encoder.lexPerms
  • ConwayO7.Encoder.orbitPerm

Let \(N \le S_{99}\) be generated by: the block transposition exchanging \(7\)-blocks \(0,1\); the transpositions of adjacent blocks \(i,i{+}1\) for \(2 \le i \le 12\); the rotations of each block; and the five multiplier permutations \(j \mapsto aj \bmod 7\) (\(2 \le a \le 6\)) applied simultaneously to all blocks. Each \(\rho \in N\) normalises \(\langle \sigma _0\rangle \), hence acts on the orbit space and thus on words \(\{ 0,1\} ^{693}\) by \((\rho \cdot \omega )(o) = \omega (\rho ^{-1}o)\). The encoding uses \(101\) fixed generators of this action.

Definition 68 Block relabellings
✓

Uses

Lean declarations

Write \(B_i = \{ 1+7i,\dots ,7+7i\} \) (\(0 \le i \le 13\)) for the fourteen \(7\)-blocks rotated by \(\sigma _0\). A permutation \(\tau \in S_{14}\) of the block indices induces a permutation of the \(99\) vertices fixing \(0\) and sending the \(j\)-th vertex of block \(i\) to the \(j\)-th vertex of block \(\tau (i)\): block indices are permuted, positions within blocks are kept.

Lemma 69 Relabelling blocks commutes with rotating within blocks
#

Uses

  • Definition 68
  • Definition 22

Lean declarations

  • ConwayO7.Encoder.cycleRelabel_comm
  • ConwayO7.Encoder.cycleRelabelVal_comm

Every block relabelling commutes with \(\sigma _0\).

Proof sketch ▶

In the coordinates (block index, position within block) of a nonzero vertex, \(\sigma _0\) increments the position modulo \(7\) and fixes the block index, while a block relabelling permutes the block index and fixes the position; the two actions touch disjoint coordinates. Both maps fix the vertex \(0\).
