Let \(\Gamma \) be an \(\mathrm{srg}(99,14,1,2)\) and let \(\pi \) be an automorphism of order \(7\). Then \(\pi \) has exactly one fixed vertex, and its cycle type is \(1 + 7 \cdot 14\): one fixed point and fourteen \(7\)-cycles.

Proof sketch ▶

Since \(\operatorname {ord}\pi = 7\) is prime, every cycle of \(\pi \) has length \(1\) or \(7\), so \(|\operatorname {Fix}\pi | \equiv 99 \equiv 1 \pmod7\). A counting argument on common neighbours excludes \(|\operatorname {Fix}\pi | \ge 2\): the fixed set induces a subgraph in which the strong regularity parameters \((\lambda ,\mu ) = (1,2)\) force contradictory neighbour counts modulo \(7\). Hence exactly one fixed vertex, and \(99 = 1 + 7\cdot 14\) determines the cycle type.

If some \(\mathrm{srg}(99,14,1,2)\) has an automorphism of order \(7\), then some \(\mathrm{srg}(99,14,1,2)\) on the vertex set \(\{ 0,\dots ,98\} \) is invariant under \(\sigma _0\). Consequently, if no \(\sigma _0\)-invariant \(\mathrm{srg}(99,14,1,2)\) exists, then \(7 \nmid |\operatorname {Aut}\Gamma |\) for every \(\mathrm{srg}(99,14,1,2)\) \(\Gamma \).

Proof sketch ▶

Transport \(\Gamma \) to \(\{ 0,\dots ,98\} \) along any bijection. By Lemma 4 the resulting automorphism \(\pi \) has the same cycle type as \(\sigma _0\); two permutations of equal cycle type are conjugate in the symmetric group, say \(\tau \pi \tau ^{-1} = \sigma _0\). The relabelled graph \(\tau (\Gamma )\) is again an \(\mathrm{srg}(99,14,1,2)\) and is \(\sigma _0\)-invariant.
