5.1 Propositional formulas from first principles

Definition 94 Variables and literals
✓
#

Lean declarations

  • Std.Sat.Literal

Fix a countable index set \(V\) of variables; concretely \(V = \{ 0, 1, 2, \dots \} \). A literal is a pair \((x, \varepsilon ) \in V \times \{ 0,1\} \), written \(x\) when \(\varepsilon = 1\) and \(\neg x\) when \(\varepsilon = 0\): an assertion that the variable \(x\) takes the value \(\varepsilon \).

source: mathlib / Lean core

Definition 95 Clauses and formulas
✓
#

Uses

  • Definition 94

Lean declarations

  • Std.Sat.CNF
  • Std.Sat.CNF.Clause

A clause is a finite list of literals, read disjunctively (“at least one of these assertions holds”). A formula in conjunctive normal form (a CNF formula) is a finite family \(F = (C_1, \dots , C_m)\) of clauses, read conjunctively (“every clause holds”).

source: mathlib / Lean core

Definition 96 Valuations and satisfaction
✓
#

Uses

  • Definition 95

Lean declarations

  • Std.Sat.CNF.eval
  • Std.Sat.CNF.Clause.eval

A valuation is a function \(a \colon V \to \{ 0,1\} \), assigning a value to every variable. A valuation \(a\) satisfies

  • the literal \((x, \varepsilon )\) iff \(a(x) = \varepsilon \);

  • a clause \(C\) iff it satisfies at least one literal of \(C\);

  • a CNF formula \(F\) iff it satisfies every clause of \(F\).

In Lean these are the evaluation maps sending a valuation and a clause/formula to \(\{ 0,1\} \); satisfaction means evaluating to \(1\).

source: mathlib / Lean core

Definition 97 Satisfiability
✓
#

Uses

  • Definition 96

Lean declarations

  • Std.Sat.CNF.Sat
  • Std.Sat.CNF.Unsat

A CNF formula \(F\) is satisfiable if some valuation satisfies it, and unsatisfiable if no valuation does. Unsatisfiability of a suitable formula is the finitary statement to which the non-existence theorem of this project is reduced.

source: mathlib / Lean core

Definition 98 Cubes: partial valuations
✓
#

Uses

  • Definition 94
  • Definition 96

Lean declarations

  • ConwayO7.Cube
  • ConwayO7.Cube.eval

A cube is a finite list of literals read conjunctively (“all of these assertions hold”) — dually to a clause. A valuation satisfies a cube \(c\) iff it satisfies every literal of \(c\); thus a cube whose variables are pairwise distinct is the same thing as a partial valuation with finite domain, and its satisfaction set is the set of all total valuations extending it.

source: ConwayO7/Semantics.lean

Definition 99 Adjoining a cube to a formula
✓
#

Uses

  • Definition 95
  • Definition 98

Lean declarations

  • ConwayO7.withCube

For a CNF formula \(F\) and a cube \(c\), the formula \(F \wedge c\) is obtained by adjoining to \(F\) one singleton clause \(\{ \ell \} \) per literal \(\ell \) of \(c\). This is the formula whose refutation certifies that \(F\) has no satisfying valuation inside the cell described by \(c\).

source: ConwayO7/Semantics.lean

Lemma 100 Semantics of \(F \wedge c\)
#

Uses

  • Definition 99
  • Definition 96

Lean declarations

  • ConwayO7.eval_withCube

A valuation satisfies \(F \wedge c\) if and only if it satisfies both \(F\) and the cube \(c\).

source: ConwayO7/Semantics.lean

Proof sketch ▶

Induction on the list \(c\): a singleton clause \(\{ \ell \} \) is satisfied exactly when the literal \(\ell \) is, and adjoining a clause intersects the satisfaction sets.

Theorem 101 Composition of refutations
#

Uses

  • Definition 97
  • Definition 99
  • Lemma 100

Lean declarations

  • ConwayO7.unsat_of_cubes

Let \(F\) be a CNF formula and let \(c_1, \dots , c_N\) be cubes whose satisfaction sets cover the space of valuations (every valuation satisfies some \(c_i\)). If \(F \wedge c_i\) is unsatisfiable for every \(i\), then \(F\) is unsatisfiable.

source: ConwayO7/Semantics.lean

Proof sketch ▶

Any valuation satisfying \(F\) satisfies some \(c_i\), hence by Lemma 100 it satisfies \(F \wedge c_i\), contradicting the \(i\)-th refutation.

Definition 102 The audited text convention
✓
#

Uses

  • Definition 95
  • Definition 98

Lean declarations

  • ConwayO7.Dimacs.litOfInt
  • ConwayO7.Dimacs.parseDimacs
  • ConwayO7.Dimacs.serializeDimacs
  • ConwayO7.Dimacs.parseCubes
  • ConwayO7.Dimacs.serializeCubes

The distributed files render literals as signed integers: the literal \((v, 1)\) (with \(v\) counted from \(0\)) is written as the integer \(v+1\), and \((v, 0)\) as \(-(v+1)\). A clause is a line of literals terminated by \(0\); a cube is a line of literals with no terminator. The parsing maps from text to formulas and cubes, and the serialisation maps in the other direction, are fixed once in a deliberately small Lean file; on the artifact files they are mutually inverse byte for byte, which is what gives the byte-identity facts (such as Fact 43) their meaning.

source: ConwayO7/Dimacs.lean
