The value of a word \(\omega \in \{ 0,1\} ^{693}\) is \(\mathrm{val}(\omega ) = \sum _{i{\lt}693} \omega (i)\, 2^{692-i}\), the word read as a big-endian binary number.

Lemma 83 Value order refines lexicographic order
#

Uses

  • Definition 82

Lean declarations

  • ConwayO7.Encoder.lex_of_val_le

Let \(u, w \in \{ 0,1\} ^{693}\) with \(\mathrm{val}(u) \le \mathrm{val}(w)\). Then for every position \(i {\lt} 693\): if \(u\) and \(w\) agree at all positions \(j {\lt} i\) and \(u(i) = 1\), then \(w(i) = 1\). Equivalently, \(u \preceq w\) in the lexicographic order.

Proof sketch ▶

Suppose \(u(i)=1\) but \(w(i)=0\) with equal prefixes below \(i\). Split both values at position \(i\): the prefix contributions coincide, the bit of \(u\) at \(i\) contributes \(2^{692-i}\), and the tail of \(w\) is at most \(\sum _{t{\lt}692-i} 2^t = 2^{692-i}-1\). Hence \(\mathrm{val}(u) {\gt} \mathrm{val}(w)\), a contradiction.

Lemma 84 Existence of a reachable minimum
#

Uses

  • Definition 80
  • Definition 82

Lean declarations

  • ConwayO7.Encoder.exists_min_reach

For every \(\omega \) there is \(\omega _{\min } \in \mathcal{R}(\omega )\) with \(\mathrm{val}(\omega _{\min }) \le \mathrm{val}(\omega ')\) for all \(\omega ' \in \mathcal{R}(\omega )\).

Proof sketch ▶

The set of values of reachable words is a nonempty set of natural numbers; by well-ordering it has a least element, attained by some reachable word.
